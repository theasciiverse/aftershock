Map check, LibreQuake v0.09-beta episodes 1 to 4 (2026-11-28)

Made by tools/check-maps.py --jobs 4 on Linux x86-64, Aftershock 0.3.0
work, skill Normal. For each map: it parses; a flood fill of the player's
hull from the start (through teleporters, ignoring gravity, doors and
lifts) reaches the exit; the game runs it for 30 seconds in god mode with
no error in the log; and the player, put in each exit's touch box while
holding fire, sees the intermission and the next map load.

Left out of this file: the engine's "'<key>' is not a field" notes, for
map keys the game code has no use for (mapversion, fog, alpha, credits,
the compilers' light settings and so on), which every map has.

Ten maps are LibreQuake's placeholders for levels not made yet: an
untitled corridor with a teleporter on to the next map. They load, run
and lead on like the rest; the episodes pass through them.
